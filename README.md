# Araba Kiralama Otomasyonu

Bu proje, C# ve MS SQL Server kullanılarak geliştirilmiş bir araba kiralama otomasyon sistemidir.

## Proje Hakkında

Bu masaüstü uygulaması, bir araba kiralama şirketinin operasyonlarını yönetmek için tasarlanmıştır. Müşteri yönetimi, araç filosu takibi, kiralama ve iade işlemleri gibi temel modülleri içerir.

## Kullanılan Teknolojiler

*   **Platform:** C# Windows Forms (.NET Framework)
*   **Veritabanı:** Microsoft SQL Server

## Kurulum ve Başlangıç

Projeyi yerel makinenizde kurup çalıştırmak için aşağıdaki adımları izleyin:

1.  **Repoyu Klonlayın:**
    ```sh
    git clone https://github.com/KeremOgzhn/ArabaKiralama.git
    ```

2.  **Veritabanını Ayarlayın:**
    - Proje içerisinde bulunan SQL script'lerini kullanarak veritabanını ve tabloları oluşturun.
    - `app.config` dosyasındaki veritabanı bağlantı dizesini (`connectionString`) kendi MS SQL Server yapılandırmanıza göre güncelleyin.

3.  **Projeyi Çalıştırın:**
    - `ArabaKiralama.sln` dosyasını Visual Studio ile açın.
    - Projeyi derleyin ve başlatın.
